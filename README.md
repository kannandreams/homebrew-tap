# kannandreams/homebrew-tap

Homebrew formulae for tools built by [@kannandreams](https://github.com/kannandreams).

```sh
brew install kannandreams/tap/<formula>
```

| Formula | What it is |
|---|---|
| [`agent-top`](https://github.com/kannandreams/agent-top) | htop for local coding agents: processes, subagents, MCP servers, tokens, cost and a per-call tool trace in one terminal view |

Formulae here are generated by each project's release workflow on tag. Edit the
template in the source repository, not the `.rb` file here — a release
overwrites it.
